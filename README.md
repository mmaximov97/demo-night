# demo-night

Companion page for a 10-minute demo at **Demo Night Belgrade**, 19 August 2026.

Live: https://mmaximov97.github.io/demo-night/

The talk is about the context system behind the agents I run — three rules
(collect, curate, reach), the WireGuard setup that makes a phone a working
terminal, and links to the tools involved.

Single static `index.html`, no build step. Push to `main` publishes it.
